# 💼 CareerHub - Job Portal Landing Website

CareerHub is a premium, modern, and fully responsive Job Portal Landing Website designed to connect top talent with industry-leading companies. Built using clean **HTML5**, **CSS3 (Vanilla)**, and **JavaScript (ES6)**, it features a sleek glassmorphic UI, rich micro-interactions, dynamic job filtering, and interactive components.

## ✨ Features

- **💫 Custom Preloader Screen:** A smooth, professional loading experience before the page reveals.
- **🔍 Interactive Search Widget:** Live search layout filtering by Job Title, Location, and Categories.
- **⚡ Dynamic Job Filtering:** Fast client-side job filtering (All, Full-Time, Part-Time, Remote) with smooth scale and fade transitions.
- **💬 Testimonials Slider:** An auto-playing customer review carousel with touch/click control buttons.
- **📱 Fully Responsive Design:** Handcrafted media queries ensuring a flawless user experience across mobile, tablet, laptop, and ultra-wide screens.
- **🎨 Modern Premium Aesthetics:** Harmony-driven custom HSL color palette, glassmorphic headers, beautiful card hover micro-animations, and custom scroll-reveal animations.
- **📈 Trust Statistics & Floating Badges:** Interactive statistics counter layout and floating application feedback badges for high visual appeal.
- **🔍 SEO Optimized:** Configured semantic HTML5 structure and SEO meta tags for enhanced search ranking.

---

## 🛠️ Tech Stack & Libraries

- **Markup:** Semantic HTML5
- **Styling:** Vanilla CSS3 (Custom Properties / Flexbox / CSS Grid / Keyframe Animations)
- **Interactivity:** Vanilla JavaScript (ES6 DOM Manipulation)
- **Icons:** [Boxicons CDN](https://boxicons.com/)
- **Fonts:** [Google Fonts](https://fonts.google.com/) (Inter / Outfit / Roboto)

## ⚙️ How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/JOB-PORTAL-LANDING-WEBSITE.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd JOB-PORTAL-LANDING-WEBSITE
   ```
3. **Open `index.html`:**
   - Double-click the `index.html` file to open it in your browser.
   - *Or* run it using a local development server like **VS Code Live Server**.
